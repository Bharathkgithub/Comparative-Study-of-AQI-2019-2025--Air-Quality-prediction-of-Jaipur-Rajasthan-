# Data

`cleaned_station_daily_with_AQI.csv`: cleaned daily station data for Jaipur (2019–2025) with computed sub-indices, AQI and AQI category.

Columns include: `Date`, pollutants (`SO2`, `Ozone`, `NOx`, `NH3`, `CO`, `NO`, `NO2`, `PM10`, `PM2.5`, VOCs), meteorology (`Wind Speed`, `Wind Direction`, `Barometric Pressure`, `RH`, `Solar Radiation`), sub-indices, `AQI` and `AQI_Category`.

Raw sources:
- CPCB: https://cpcb.nic.in (NAMP / AQI bulletin archive)
- NASA POWER: https://power.larc.nasa.gov
